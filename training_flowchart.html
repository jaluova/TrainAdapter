GridGround 训练流程

一个轻量级的空间定位 Adapter：给一张图和一句话（如"左边的红色车"），在 11x11 的网格上预测目标位置。
核心思想 —— 冻结大模型 Qwen2.5-VL，只训练一个小小的 Adapter。

类比：想象你有一位经验丰富的老师（Qwen 大模型）和一个学生（Adapter）。老师已经学会了看图和理解语言，但不需要再学新东西。学生的任务是：听老师描述图片内容和文字含义，然后在一张 11x11 的棋盘上落子，指出"那个东西在哪"。训练的过程就是不断让学生练习落子，直到越来越准。
Phase 1 · 数据准备
📁
原始数据加载
从 grefs_with_grids.json 读取标注，每条数据包含三样东西：
  • 原始图片 — 一张普通照片（如一群人在公园里）
  • 网格图片 — 同一张照片上叠加了 11x11 的参考网格线
  • 文字查询 — 一句自然语言描述（如"左边穿红衣服的人"）
  • 标注答案 — 目标在网格中的位置，如 [2,5] 表示第 2 列第 5 行
类比：就像一道考试题 —— 给你一张照片、一张带坐标的照片、一个提问，以及标准答案。
⚙
数据预处理
把原始数据转换成模型能理解的格式：
  • 图片 → 张量：将图片转为数字矩阵 [3, 448, 448]（3 个颜色通道）
  • 文字 → Token ID：将文字拆分为模型能理解的编号序列 [512]
  • 坐标 → 归一化：[2, 5] → [0.2, 0.5]（除以 10，变成 0~1 的比例）
  • 构建网格标签：创建 121 维的"答案"向量 [121]
      正确格子 = 1.0  |  相邻格子 = 0.3（柔和标签） |  其余 = 0.0
  • 查询分类：标记是否为关系词（"左边"）、颜色词（"红色"）等
类比：把中文题目翻译成模型的"母语"（数字），同时把答案从"第 2 列第 5 行"变成一张答题卡（121 个格子涂黑正确的）。
Phase 2 · 特征提取（冻结大模型）
👁
Qwen 视觉编码器 冻结
大模型"看"原始图片，输出对图片的理解：
图片 [B, 3, 448, 448] → 视觉特征 [B, 196, 768]

196 = 14×14，相当于把图片分成 14×14 的区域，每个区域用 768 个数字描述

类比：老师看了图片，给出 196 段"这里有什么"的描述。
💬
Qwen 文本编码器 冻结
大模型"读"文字查询，输出对文字的理解：
Token IDs [B, 512] → 文本特征 [B, 512, 768]

每个词用 768 个数字表示其含义和上下文关系

类比：老师读懂了题目，理解了"左边穿红衣服的人"是什么意思。
Phase 3 · Adapter 核心处理（这才是训练的重点！）
🔍
Step 3a · 网格编码器 (GridEncoder) 可训练
用一个小型 CNN 分析网格图片，提取网格的空间结构信息：
网格图片 [B,3,448,448]
→
4层残差CNN
→
特征图 [B,512,14,14]
→
投影+位置编码
→
网格Token [B,64,768]

64 个 Token = 将网格图的空间信息压缩成 64 段描述，每段 768 维

类比：学生拿到带网格的图片，先仔细看清楚网格线的布局，记住哪个位置对应哪个格子。
🔄
Step 3b · 交叉注意力 (CrossAttention) 可训练
让老师的"图片理解"和学生的"网格理解"进行深度对话：
视觉特征 [B,196,768]
+
网格Token [B,64,768]
→
注意力融合
→
增强特征 [B,196,768]
  • Q(查询) 来自视觉特征 —— "图片中这个区域有什么？"
  • K/V(键/值) 来自网格 Token —— "这个区域对应网格的哪个位置"
  • 通过 8 头注意力，让每个图片区域都知道自己在网格中的位置
类比：学生把老师说的"图片内容"和自己看到的"网格位置"对应起来 —— "老师说的那个红色物体，是在网格的第 3 行第 2 列"。
🚪
Step 3c · 门控融合 (GatedFusion) 可训练
用一个可学习的"门"来决定：对于每个区域，应该更信任原始视觉特征还是网格增强的特征？
gate = sigmoid(MLP([原始特征, 增强特征]))
输出 = gate × 增强特征 + (1 - gate) × 原始特征

gate 接近 1 → 更信任增强后的  |  gate 接近 0 → 保留原始的

类比：学生学会判断 —— 对于某些简单区域，老师的原始理解就够了；对于位置相关的复杂区域，需要加入网格信息。
🎯
Step 3d · 文本引导 + 网格预测 可训练
最关键的一步 —— 根据文字查询，在 121 个格子上预测目标位置：
  • 文本池化：将 512 个词向量压缩成一个语义概括 [B, 768]
  • 文本调制：用文字含义去"调整"每个视觉区域的重要性（类似 FiLM 调制）
  • 网格分类头：每个视觉 Token 预测 121 个格子的得分 [B, 196, 121]
  • Token 加权聚合：学习每个视觉 Token 的重要性权重，加权求和 [B, 121]
  • 解码 Top-4：取得分最高的 4 个格子，转换为坐标 [B, 4, 2]
维度变化：融合特征 [B,196,768] → 条件化 [B,196,768] → 121 维网格 logits [B,121] → Top-4 坐标 [B,4,2]
类比：学生听完题目"左边穿红衣服的人"，结合对图片和网格的理解，在 121 个格子里选出最可能的 4 个位置落子。
Phase 4 · 损失计算（"打分"）
📊
BCE + Ranking Loss
计算预测和答案之间的差距，由两部分组成：
  • 分类损失 (BCE)：对每个格子问"预测对了吗？" —— 用二元交叉熵衡量。正确格子被赋予 4 倍权重（因为正确格子很少，需要重点关注）
  • 排序损失 (Ranking)：确保正确格子的得分 > 错误格子的得分。如果某个错误格子得分太高，就额外惩罚
  • 总损失：分类损失 + 0.25 × 排序损失
类比：批改试卷 —— 第一项看答对了几个（分类），第二项看有没有把错的答案排在对的前面（排序）。两项加权算总分。
Phase 5 · 反向传播 & 参数更新
🚀
AdamW 优化器 + 余弦退火
  • 反向传播：从损失出发，计算每个 Adapter 参数应该怎么调（梯度只流过 Adapter，不流向冻结的 Qwen）
  • 梯度裁剪：如果梯度太大就截断（max_norm=1.0），防止训练不稳定
  • 参数更新：AdamW 优化器沿梯度方向微调 Adapter 的权重
  • 学习率调度：先热身（前 200 步逐渐增大 LR），再余弦退火（像日落一样缓慢降低）
关键点：整个过程只修改 Adapter 的参数（约几百万个），Qwen 大模型的数十亿参数始终不变。这就是"参数高效微调"的核心思想。
类比：根据批改结果，学生调整自己的答题策略 —— 老师不需要改变（已经很厉害了），只有学生在不断进步。学习率就像"改正幅度"，开始大步改、后面小步微调。
Phase 6 · 评估验证（每 500 步）
✅
验证集评估 & 保存最优模型
在验证集上测试当前模型表现，不更新参数：
  • Acc@1Grid：Top-1 预测恰好命中正确格子的比例（最严格）
  • Acc@Top4：Top-4 预测中任何一个命中正确格子的比例（主要指标）
  • Relation Acc@Top4：含空间关系词（左/右/之间）的查询准确率
  • Color Acc@Top4：含颜色描述的查询准确率
如果表现优于历史最佳 → 保存为 best_model.pth
自动清理旧 checkpoint，只保留最近 3 个 + best
类比：每学习 500 道题就做一次模拟考试，如果创了新高分就把当前状态记录下来。
